## Описание
Десктопное приложение для управления складскими запасами. Позволяет вести учёт различных типов партий товаров, добавлять новые записи, редактировать существующие и сохранять данные в файл формата `.csv`.

## Реализованный функционал
- **Иерархия классов:**
    - Реализован базовый класс `Batch` и его наследник `ImportBatch` (Импортная партия с доп. полями: страна, таможенный код).
    - Реализован класс `ArchiveBatch` (Архивная партия) в виде Java `record` (read-only сущность).
- **Интерфейс `Editable`:** Используется как контракт для редактируемых сущностей. Кнопка "Изменить запись" в GUI автоматически блокируется при выборе read-only партий (`ArchiveBatch`).
- **Собственная система исключений:** Разработан класс `CsvParseException` с перечислением `CsvErrorCode` для точечной обработки ошибок чтения файлов (неверное количество колонок, ошибки парсинга чисел и дат, неизвестный тип партии).
- **Работа с файлами:** Чтение и сохранение данных в `.csv` по контракту (10 фиксированных колонок). Битые или некорректные строки обрабатываются с выводом информативных диалоговых окон.

## Структура проекта (Package by Layer)
- `model/` — сущности предметной области (`StorageItem`, `Batch`, `ImportBatch`, `ArchiveBatch`, `Editable`).
- `view/` — визуальные компоненты JavaFX без бизнес-логики (`MainView`, `BatchFormView`, `StorageTableView`).
- `controller/` — связующее звено, обработка событий и управление состоянием (`MainController`, `BatchFormController`).
- `util/` — утилиты для работы с файловой системой (`CsvStorageUtil`) и диалоговыми окнами (`AlertUtil`).
- `exception/` — кастомные классы ошибок.

## Формат данных 
Приложение ожидает файл `data.csv` со строго фиксированным порядком колонок:\
`Тип партии;Артикул;Наименование;Количество;Ячейка;Дата поступления;Страна;Таможенный код;Дата архивации;Причина архивации`
